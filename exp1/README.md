# Experiment 1: Introduction to LEX Tool, Metadata and Patterns

**Course Outcome:** CO1

## 1. Objective
To understand the structure of a LEX (Lexical Analyzer Generator) program, learn about metadata variables and functions (`yytext`, `yyleng`, `yylex`, `yywrap`), and practice regular expression patterns.

## 2. Structure of a LEX Program
A standard Lex program consists of three sections separated by `%%`:

```lex
%{
    /* Section 1: Declarations & C Header Inclusions */
    #include <stdio.h>
%}

/* Definitions / Regular Definitions */
DIGIT   [0-9]
LETTER  [a-zA-Z]

%%
/* Section 2: Translation Rules (Pattern & Action) */
{DIGIT}+    { printf("Number: %s\n", yytext); }
{LETTER}+   { printf("Word: %s\n", yytext); }
.|\n        ;
%%

/* Section 3: User Auxiliary Functions */
int main() {
    yylex();
    return 0;
}
```

## 3. Metadata and Predefined Variables in LEX
- `yytext`: A null-terminated C string (`char*`) holding the lexeme matched by the current pattern.
- `yyleng`: An integer representing the length of the string in `yytext`.
- `yylex()`: The main scanning function generated by Lex. It reads from `yyin` and returns tokens or executes actions.
- `yywrap()`: Called when the scanner reaches EOF (`End of File`). If it returns 1, scanning terminates; if 0, scanning continues with a new file.
- `yyin`: Pointer to input file (`FILE*`), defaults to `stdin`.
- `yyout`: Pointer to output file (`FILE*`), defaults to `stdout`.

## 4. Common Regular Expression Patterns & Metacharacters
| Metacharacter | Description | Example |
| :--- | :--- | :--- |
| `.` | Matches any single character except `\n` | `a.c` matches `abc`, `a1c` |
| `*` | Zero or more occurrences of preceding element | `a*` matches `""`, `a`, `aaa` |
| `+` | One or more occurrences of preceding element | `[0-9]+` matches numbers |
| `?` | Zero or one occurrence (optional) | `-?[0-9]+` matches signed numbers |
| `[abc]` | Any one character from the set | `[aeiou]` matches a vowel |
| `[^abc]` | Any character NOT in the set | `[^0-9]` matches non-digits |
| `[a-z]` | Range of characters | `[a-zA-Z]` matches alphabets |
| `^` | Anchor to beginning of a line | `^Title` |
| `$` | Anchor to end of a line | `end$` |
| `|` | Alternation (OR) | `cat|dog` |
| `()` | Grouping | `(ab)+` matches `ab`, `abab` |
| `\ ` | Escape metacharacters | `\+`, `\*`, `\.` |
